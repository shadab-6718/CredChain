2. UML Dynamic Sequence Diagram (4-Stage Progressive Lifecycle)

sequenceDiagram
    autonumber
    actor Issuer as 🏛️ Issuer (University)
    actor Holder as 👤 Holder (Student)
    boundary UI as 💻 Frontend (Web App)
    control API as 🖥️ Backend API
    database IPFS as 📦 IPFS Storage
    entity Chain as ⛓️ Blockchain (Polygon)
    actor Verifier as 🔍 Verifier (Employer/Bank)

    %% 1. ISSUE CREDENTIAL
    rect rgb(30, 41, 59)
    note over Issuer, UI: Stage 1: Issue Credential
    Issuer->>UI: Upload document & select type (Milestone / Final Degree)
    UI->>UI: Compute SHA-256 Document Hash
    end

    %% 2. STORE DOCUMENT
    rect rgb(15, 23, 42)
    note over UI, IPFS: Stage 2: Encrypt & Store Off-Chain (Two-Zone Privacy)
    UI->>UI: Encrypt file client-side (AES-256 GCM)
    UI->>IPFS: Upload encrypted payload
    IPFS-->>UI: Return Content ID (CID)
    end

    %% 3. RECORD ON BLOCKCHAIN
    rect rgb(30, 41, 59)
    note over UI, Chain: Stage 3: Record Immutable Proof on Blockchain
    UI->>API: Submit Anchor Request (SHA-256 Hash, IPFS CID, Parent Milestone)
    API->>Chain: issueCredential(hash, CID, parentMilestoneId)
    Chain->>Chain: Validate issuer DID whitelist & prerequisite milestone chain
    Chain-->>API: Emits CredentialIssued(txHash, blockNumber)
    API-->>UI: Return transaction receipt & generate verifiable QR code
    UI-->>Holder: Deliver credential to Holder Wallet
    end

    %% 4. VERIFY / ACCESS
    rect rgb(15, 23, 42)
    note over Verifier, Chain: Stage 4: Dual-Gate Verification & Time-Boxed Consent
    Verifier->>UI: Scan QR code / query credential ID
    UI->>Chain: verifyCredential(credentialId)
    Chain-->>UI: Return on-chain status (VALID / REVOKED) + Milestone Audit Trail
    
    opt Document Inspection with Consent
        Verifier->>API: Request access to encrypted document
        API->>Holder: Inbound access notification (24h-30d time-box)
        Holder->>API: Approve bilateral consent grant
        API->>IPFS: Fetch encrypted document via CID
        IPFS-->>UI: Stream encrypted payload
        UI->>UI: Decrypt payload using holder-shared session key
        UI-->>Verifier: Display authentic verified document
    end
    end
